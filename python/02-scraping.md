# 爬网页：requests、BeautifulSoup、文本清洗

---

### `requests.get(网址, headers={"User-Agent": ...})`

- 作用：发 GET 请求取网页；带上浏览器的 User-Agent
- 说法：请求网页；爬网页；伪装浏览器
- 分类：爬网页
- 项目：豆瓣：Top250 共 10 页，翻页爬取
- 坑：不带 User-Agent 容易被拒

### `requests.get(网址, params={...}, timeout=10)`

- 作用：`params` 让 requests 帮你拼查询参数；`timeout` 最多等几秒
- 说法：带参数请求；调接口；超时设置
- 分类：爬网页
- 项目：Steam：`params={"appid": app_id}` 调 Steam 接口
- 坑：不设 timeout，网络卡住时脚本会一直挂着

### `resp.json()`

- 作用：把返回的 JSON 转成 Python 字典
- 说法：解析 JSON；接口返回的数据
- 分类：爬网页
- 项目：Steam：`resp.json()["response"]`，`result` 不是 1 就是没数据
- 坑：还没发售的游戏返回 `result` 42，不插入，返回 `None` 交给调用方处理

### `time.sleep(秒)`

- 作用：每次请求之间停一下
- 说法：限速；别请求太快；礼貌爬取
- 分类：爬网页
- 项目：豆瓣：翻页之间 sleep；Steam：每款游戏间隔 1 秒

### 失败重试

- 作用：请求失败等几秒再试，最多几次；最后一次还失败就抛出
- 说法：自动重试；网络抖动；失败再来
- 分类：爬网页
- 项目：Steam：`fetch_with_retry` 最多 3 次，每次等 5 秒
- 坑：最后一次失败后不要再打印“5 秒后重试”

### BeautifulSoup：`find` / `find_all` / `class_=`

- 作用：在 HTML 里找第一个 / 所有符合条件的标签；按 class 找要写 `class_`
- 说法：解析网页；找标签；提取内容
- 分类：爬网页
- 项目：豆瓣：每部电影一个块，取片名、评分、年份、国家、类型、导演
- 坑：Python 3.6 上 bs4 要降到 4.11.2

### `repr(文本)`

- 作用：显示字符串的真实样子，看得到 `\xa0`、`\n` 这些不可见字符
- 说法：看清脏文本；看隐藏字符；为什么切不开
- 分类：爬网页
- 项目：豆瓣：发现年份、国家、类型之间隔的是 `\xa0`（不换行空格）

### 切分清洗：`replace('\xa0', ' ')`、`split('/')`、`strip()`

- 作用：替换掉特殊空格、按分隔符切开、去首尾空白
- 说法：清洗文本；按斜杠切开；去空格
- 分类：爬网页
- 项目：豆瓣：一行文字切成年份、国家、类型

### 负下标 `parts[-2]`、`parts[-1]`

- 作用：从后往前取，前面有几段都不影响
- 说法：取最后一个；倒数第二个；从后面取
- 分类：爬网页
- 项目：豆瓣：国家永远是倒数第 2 段、类型永远是倒数第 1 段
- 坑：有多个上映年份的电影（如《大闹天宫》）多出几段，从前往后按位置取就错位了

### `str.replace('...', '')` vs `rstrip('.')`

- 作用：删掉指定的子串；`rstrip` 删的是末尾所有属于这些字符的字符
- 说法：去掉省略号；删末尾字符
- 分类：爬网页
- 项目：豆瓣：去掉被截断的导演名后面的 `...`
- 坑：`rstrip('.')` 会把名字末尾真正的句点也删掉

### 防御异常记录 + 测试脚本

- 作用：字段数不对时记日志、跳过；改爬虫前先写测试脚本，用真实页面跑边界情况
- 说法：数据格式不对；容错；先测试再改
- 分类：爬网页
- 项目：豆瓣：导演名被 `&nbsp;` 截断、被页面截断两种情况，先在测试脚本里复现再改 `spider.py`，改完做回归测试
- 坑：测试脚本和正式代码各写一份逻辑，改了一边忘了另一边就对不上

### `pip install --trusted-host 源地址`

- 作用：信任这个 pip 源，跳过 SSL 证书校验
- 说法：pip 证书报错；SSL 错误装不上包
- 分类：Python 环境
- 项目：豆瓣早期在 CentOS 7 的 Python 3.6 上装包

### `resp.raise_for_status()` 与状态码

- 作用：状态码不是 2xx 就抛 `HTTPError`。2xx 成功、3xx 跳转、4xx 请求方的问题、5xx 服务器的问题。429 是限流，等一会儿能好；403 禁止、400 参数错，等多久都不会好，要大声报错
- 说法：检查请求成没成功；HTTP 状态码；429 和 403 区别；被限流
- 分类：爬网页
- 项目：Steam：评论接口 429 时记 WARNING、保存进度、正常退出；其他 HTTP 错误照样抛出，让健康检查能看到

### 只对超时和连接错误重试

- 作用：`requests.RequestException` 是所有请求异常的父类，包括 `HTTPError`；重试时只接 `Timeout`、`ConnectionError`，否则 429、403 也会被盲目重试
- 说法：网络抖动自动重试；超时重试；哪些错误要重试
- 分类：爬网页
- 项目：Steam：补历史因 TLS 握手超时、读取超时退出过两次，加了 `fetch_with_retry`（等 10 秒、最多 3 次）

### cursor 翻页

- 作用：接口返回一个 `cursor`，下一页带上它。按“最新”排序时新内容不断插到前面，页码会漂移，cursor 记的是位置不受影响；翻到底时返回空列表或同一个 cursor
- 说法：翻页；分页接口；下一页怎么拿；断点续翻
- 分类：爬网页
- 项目：Steam：评论按最新排序翻页，每日增量“一页全是存过的就停”，补历史不因存过而停

### Service 接口的 `input_json`

- 作用：Steam 的 Service 类接口把所有参数写成一段 JSON，放在 `input_json` 一个参数里；`json.dumps(字典)` 转字符串，`requests` 自动 URL 编码
- 说法：参数是 JSON；Steam 新接口怎么传参
- 分类：爬网页
- 项目：Steam：旧的 `store.steampowered.com/appreviews` 10/22 停用，换成 `api.steampowered.com/IUserReviewsService/GetAppReviews/v1/`
