# matplotlib 画图

---

### `fig, axes = plt.subplots(2, 2, sharex=True)` / `axes.flat`

- 作用：一张图里排 2×2 个子图，共用横轴；`axes.flat` 把它们摊平成一排，按编号取
- 说法：画多个子图；子图排版；共用横轴
- 分类：画图
- 项目：Steam：03 按游戏分组，一组一张子图

### `ax.axis("off")` / `ax.tick_params(labelbottom=True, which="both")`

- 作用：隐藏一个坐标区；让坐标区底部显示刻度文字（主、次刻度都要）
- 说法：隐藏空子图；子图没有横轴刻度；显示刻度
- 分类：画图
- 项目：Steam：只有 3 组时第 4 块隐藏
- 坑：`sharex` 只让最下面一行显示刻度；最下面那块被隐藏后，它正上方的子图要自己打开刻度；pandas 画时间轴时有些标签在次刻度上，只开主刻度会漏

### 中文字体：`font_manager.fontManager.addfont(路径)` + `plt.rcParams["font.family"]`

- 作用：注册一个字体文件，并设为默认字体
- 说法：中文显示成方框；中文乱码；设置字体
- 分类：画图
- 项目：Steam、豆瓣：本地准备的 SimHei 放在 `fonts/`
- 坑：字体文件不进 Git

### `df.plot(ax=ax)` / `ax.axhline(y=1)`

- 作用：在指定子图上画折线；画一条水平参考线
- 说法：画折线图；加参考线；趋势图
- 分类：画图
- 项目：Steam：04 平行趋势图，y=1 表示等于自己的平均水平

### `plot(kind="bar")` / `ax.bar_label(ax.containers[0])`

- 作用：画柱状图；在每根柱子顶上标数值
- 说法：画柱状图；柱子上标数字
- 分类：画图
- 项目：豆瓣：各年代电影数

### `ax.set_xticklabels([...], rotation=0)`

- 作用：改横轴标签文字，`rotation=0` 横着放
- 说法：改横轴文字；标签别竖着
- 分类：画图
- 项目：豆瓣：横轴写成 `1930s` 这种
- 坑：柱状图默认把横轴标签转 90 度竖起来

### `savefig(路径)`

- 作用：保存成图片文件
- 说法：保存图片；导出图表
- 分类：画图
- 项目：Steam、豆瓣：存到 `analysis/output/`
- 坑：输出目录不进 Git；先 `mkdir(exist_ok=True)`

### `ax.axvline(x)` / `ax.set_ylim(bottom=0)`

- 作用：竖线标出某个时刻；绝对数量的纵轴从 0 开始，否则波动被放大。比例类纵轴也别让它自动缩放到很窄的范围
- 说法：画一条竖线；标出发售时间；纵轴从 0 开始；图被放大误导
- 分类：画图
- 项目：Steam 06 用竖线标 10/29 10:00；07 好评率纵轴设 0.85–1.0

### 日期刻度错开 1/3 格

- 作用：`rcParams["timezone"]` 设成北京后，刻度按北京零点放；而 `dt.date` 不带时区，被当成 UTC 零点，差 8 小时。修法：`DayLocator(tz="UTC")` 和 `DateFormatter("%m-%d", tz="UTC")`；带时区的 `bj` 列则不用改
- 说法：点和刻度对不齐；日期刻度偏了；横轴错位
- 分类：画图
- 项目：Steam 04、07 都踩过

### `bar_label(容器, labels=列表)`

- 作用：自己指定每根柱子上写什么，比如 `f"{c}\n{a:.2f}分"` 两行标签；`zip` 把两列一一配对
- 说法：柱子上标多个数；自定义柱状图标签
- 分类：画图
- 项目：豆瓣 02：柱子上标部数和平均分

### `plot(kind="barh")` + `ax.invert_yaxis()`

- 作用：横向柱状图，名字长时放左边不挤；横向图默认第一行在最下面，翻转后从上往下读
- 说法：横着的柱状图；名字太长；排第一的放上面
- 分类：画图
- 项目：豆瓣 03：国家/地区前 10

### `fig, (ax1, ax2) = plt.subplots(2, 1, sharex=True)` + `ax.plot(x, y)`

- 作用：只有两张图时直接拆包；两张都用 matplotlib 画，避免 pandas 的时间轴和 matplotlib 的混用时 `sharex` 范围出错
- 说法：上下两张图；共享横轴
- 分类：画图
- 项目：Steam 06（上：影之刃零人数，下：魂类相对发售前）、07（上：每天评论数，下：好评率）
