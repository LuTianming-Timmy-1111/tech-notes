# Python 连数据库：pymysql、sqlite3、SQLAlchemy

| | pymysql（MySQL） | sqlite3（SQLite） |
|---|---|---|
| 安装 | `pip install pymysql` | 自带 |
| 连接 | 主机、端口、用户、密码、库名 | 一个文件路径 |
| 占位符 | `%s` | `?` |
| 多条 SQL | 一次 `execute` 一条 | `executescript` 一次跑完 |

套路都是：**连接 → 游标 → execute → commit → 关闭**。

---

## pymysql

### `pymysql.connect(host=..., port=..., user=..., password=..., database=..., charset='utf8mb4')`

- 作用：连 MySQL
- 说法：Python 连 MySQL；连数据库；pymysql 连接
- 分类：Python 连数据库
- 项目：豆瓣：`spider.py`、`split_tables.py`、`check.py`
- 坑：不加 `charset='utf8mb4'` 中文可能乱码；MySQL 8 默认认证方式要装 `cryptography`，或者把账号改成旧认证方式

### `cursor.execute(sql, 参数)` / `conn.commit()` / `cursor.fetchall()` / `close()`

- 作用：执行 SQL；提交；取回全部结果（元组的元组）；关闭
- 说法：执行 SQL；提交事务；取查询结果
- 分类：Python 连数据库
- 项目：豆瓣：全部插完统一 `commit`；`check.py` 用 `len(rows)` 判断有没有问题行
- 坑：参数用占位符传，不要用 f-string 拼进 SQL

### get-or-create

- 作用：先查这个名字有没有 id，有就用，没有就插入再取 id
- 说法：没有就新建；去重插入；查不到就插
- 分类：Python 连数据库
- 项目：豆瓣：拆表时 `genre`、`country`、`director` 都这样去重

### 连接重试

- 作用：连不上时等几秒再试，用 `for ... else`
- 说法：数据库还没起来；连接失败重试
- 分类：Python 连数据库
- 项目：豆瓣：爬虫容器比 MySQL 先准备好时会连不上

## sqlite3

### `sqlite3.connect(路径)` / `con.execute(sql, 参数)` / `con.commit()`

- 作用：连 SQLite；`con.execute` 是省事写法，内部自动建游标
- 说法：Python 连 SQLite；操作 SQLite
- 分类：Python 连数据库
- 项目：Steam：`init_db.py`、`collect.py`
- 坑：占位符是 `?`，不是 `%s`

### `con.executescript(文本)`

- 作用：一次执行多条 SQL
- 说法：跑整个 SQL 文件；一次建好几张表
- 分类：Python 连数据库
- 项目：Steam：`con.executescript(SCHEMA_PATH.read_text(encoding="utf-8"))` 跑 `schema.sql`

### `PRAGMA foreign_keys = ON`

- 作用：打开 SQLite 的外键检查
- 说法：SQLite 外键不生效；开启外键
- 分类：Python 连数据库
- 项目：Steam：`collect.py` 连库后第一句

### `cur.rowcount`

- 作用：这次执行影响了几行
- 说法：插入了几条；写入成功没有
- 分类：Python 连数据库
- 项目：Steam：`INSERT OR IGNORE` 插进去是 1，被忽略是 0，加起来就是“写入 X 条”

### `src.backup(dst)`

- 作用：SQLite 的备份接口，复制出一个完整、一致的快照
- 说法：备份数据库；复制数据库文件
- 分类：Python 连数据库
- 项目：Steam：`backup.py` 每天一份，只留 7 份
- 坑：不能直接 `cp` 正在被写的数据库，可能复制到写了一半的文件

## SQLAlchemy

### `create_engine("mysql+pymysql://用户:密码@地址:端口/库名?charset=utf8mb4")`

- 作用：按地址管理连接，用的时候自动连、用完自动还；`mysql` 是数据库种类，`+pymysql` 是驱动
- 说法：pandas 连 MySQL；数据库连接地址；SQLAlchemy 引擎
- 分类：Python 连数据库
- 项目：豆瓣：分析脚本 `pd.read_sql(sql, engine)`
- 坑：直接把 pymysql 连接传给 `pd.read_sql` 能用，但会出 UserWarning；pandas 只测试过 SQLAlchemy 和 sqlite3 连接
