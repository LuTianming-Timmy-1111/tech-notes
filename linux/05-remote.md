# 远程登录、传文件、端口、网络

| 现象 | 意思 |
|---|---|
| `Connection refused` | 到达了机器，但这个端口没人监听 |
| 超时 `timed out` | 半路被挡住了，比如防火墙 |

| 层 | 在哪 | 管什么 |
|---|---|---|
| 云防火墙 | 云控制台 | 外面的连接能不能到达这个端口 |
| sshd | `/etc/ssh/sshd_config` | SSH 服务在不在听这个端口 |

## 远程登录

### `ssh -p 端口 用户@主机`

- 作用：登录远程机器；`-p` 指定端口（小写）
- 说法：登录服务器；远程连接；连上去
- 分类：远程登录和传文件
- 项目：Steam：Windows PowerShell 登录云服务器
- 坑：校园网封了 22 端口，所以 SSH 另开了一个端口

### `ssh 用户@主机 命令`

- 作用：登录、执行这条命令、马上退出
- 说法：远程执行一条命令；不进去直接跑
- 分类：远程登录和传文件
- 项目：Steam：`ssh ... hostname` 测密钥能不能登录

### `ssh-keygen -t ed25519 -C "注释"`

- 作用：生成一对密钥；`.pub` 是公钥，可以给别人；没有 `.pub` 的是私钥，不外传
- 说法：生成密钥；免密登录；SSH key
- 分类：远程登录和传文件
- 项目：Steam：服务器改成只允许密钥登录
- 坑：私钥是唯一的钥匙，电脑重装就没了，要离线备份；不要放网盘、聊天软件

### sshd_config：`PasswordAuthentication no`、`PermitRootLogin prohibit-password`

- 作用：关掉密码登录，root 只能用密钥
- 说法：禁止密码登录；只用密钥；服务器加固
- 分类：远程登录和传文件
- 项目：Steam：截图里不小心露过密码，之后改成只用密钥
- 坑：🔴 新方式验证能登录之前，已经连着的那个会话不要关，它是退路；最后的退路是云控制台的 VNC

### sshd_config：`Port`

- 作用：SSH 监听哪些端口，可以写多行
- 说法：改 SSH 端口；关掉 22 端口；多开一个端口
- 分类：远程登录和传文件
- 项目：Steam：先加新端口、确认能连，再删掉 22；改完要重启 `ssh.socket`
- 坑：顺序是“先开新门，再关旧门”；关端口时先改 sshd、验证，再删云防火墙规则

### `ssh -o PubkeyAuthentication=no ...`

- 作用：故意不用密钥登录，模拟只知道密码的人
- 说法：测试密码登录关了没有
- 分类：远程登录和传文件
- 项目：Steam：直接返回 `Permission denied (publickey)`，连输密码的机会都没有，说明关成功了

## 传文件

### `scp -P 端口 源 目标`

- 作用：在本机和远程之间复制文件，远程路径写成 `用户@主机:路径`
- 说法：下载服务器上的文件；上传到服务器；传文件到虚拟机
- 分类：远程登录和传文件
- 项目：Steam：把服务器上的数据库备份下载到 D 盘，再传到虚拟机
- 坑：scp 的端口是**大写** `-P`，ssh 是小写 `-p`

### `scp -p -q -o BatchMode=yes`

- 作用：`-p` 保留原文件时间；`-q` 不显示进度条；`BatchMode=yes` 需要输密码时直接失败，不卡住
- 说法：后台自动下载；保留修改时间；不要卡在输密码
- 分类：远程登录和传文件
- 项目：Steam：Windows 任务计划每天自动下载备份
- 坑：不加 `-p`，本地文件时间是下载时间，看不出备份是哪天做的

## 端口和网络

### `ss -tlnp`

- 作用：列出正在监听的 TCP 端口和对应的进程
- 说法：看端口；哪个程序占了端口；SSH 在听哪个端口
- 分类：查进程和端口
- 项目：Steam：`ss -tlnp | grep ssh` 验证 sshd 只在新端口上监听

### `curl -x 代理 网址 -I`

- 作用：通过指定代理访问网址，`-I` 只看响应头
- 说法：测代理通不通；走代理访问；能不能上外网
- 分类：测网络连通
- 项目：练习：虚拟机测宿主机上的代理，通了才去配 Docker 代理
- 坑：超时的原因是 Windows 防火墙挡住了虚拟机的连接，还要确认代理软件的“局域网连接”开着

### `curl -sS -m 10 网址`

- 作用：`-s` 不显示进度，`-S` 但出错时仍显示错误，`-m 10` 最多等 10 秒
- 说法：测接口；请求一下看返回；测网站通不通
- 分类：测网络连通
- 项目：Steam：在服务器上直接请求 Steam 接口，确认能访问
