# 写文件、改文件

| 写法 | 效果 |
|---|---|
| `命令 > 文件` | 清空后写入 |
| `命令 >> 文件` | 追加到末尾 |
| `cat > 文件 << 'EOF'` | 把多行内容整段写成文件 |
| `sed 's/旧/新/' 文件` | 只输出替换后的结果，原文件不变 |
| `sed -i 's/旧/新/' 文件` | 直接改原文件 |

---

## 写文件、建删文件

### `cat > 文件 << 'EOF'` … `EOF`

- 作用：把两个 `EOF` 之间的多行内容写成文件（heredoc）；`'EOF'` 带引号时，里面的 `$` 不会被展开
- 说法：新建文件写内容；整段写进文件；粘贴一段代码存成文件
- 分类：改文件内容
- 项目：Steam、豆瓣：`run_collect.sh`、`backup.py`、`check.py`、logrotate 配置都是这样写的
- 坑：本该写进文件的脚本内容，直接粘到终端就会被当场执行；粘贴前先看一眼自己在哪、贴的是什么

### `echo "内容" >> 文件`

- 作用：往文件末尾追加一行
- 说法：加一行；追加到文件末尾；往配置里补一句
- 分类：改文件内容
- 项目：豆瓣：`echo "venv/" >> .gitignore`；Steam：把 `alias dev=...` 追加进 `~/.bashrc`
- 坑：写成 `>` 会把原文件清空，`.bashrc` 原来的内容就没了

### `touch 文件` / `{01..10}`

- 作用：`touch` 建空文件；`{01..10}` 是 bash 花括号展开，自动变成 01 到 10
- 说法：建个空文件；批量建文件；造测试文件
- 分类：改文件内容
- 项目：Steam：`touch backups/steam-202610{01..10}.db` 造 10 个假备份，测“只留 7 份”的清理逻辑

### `mkdir -p 路径`

- 作用：建目录，中间缺的上级目录一起建；已存在也不报错
- 说法：新建文件夹；建多层目录；目录不存在就建
- 分类：改文件内容
- 项目：练习：`mkdir -p /etc/systemd/system/docker.service.d` 放 Docker 代理配置；Steam：`run_collect.sh` 里 `mkdir -p logs`

### `rm -r 目录`

- 作用：删除目录及里面的所有东西
- 说法：删文件夹；整个目录删掉；清掉测试数据
- 分类：改文件内容
- 项目：Steam：测完清理逻辑后 `rm -r backups`，反正 `backup.py` 会自己重建

### `mv 临时文件 正式文件`

- 作用：移动或改名；先写临时文件、确认成功再 `mv` 覆盖正式文件
- 说法：改名；移动文件；替换文件
- 分类：改文件内容
- 项目：豆瓣：`dump_schema.sh` 先导出到临时文件，成功了才 `mv` 成 `schema.sql`，防止导出失败把好文件冲掉

## sed

### `sed 's/旧/新/' 文件`

- 作用：把每行第一处“旧”替换成“新”，结果输出到屏幕，原文件不变；常配合 `>` 存成新文件
- 说法：替换文字；批量改；复制一份改个名字
- 分类：改文件内容
- 项目：豆瓣：`sed 's/split_tables.py/check.py/' run_split.sh > run_check.sh` 照着旧脚本生成新脚本；`mysqldump ... | sed 's/ AUTO_INCREMENT=[0-9]*//' > schema.sql` 去掉自增计数
- 坑：`[0-9]*` 是“任意个数字”；替换内容前面带空格，是为了连同前面的空格一起删掉

### `sed 's|旧|新|'`

- 作用：分隔符不一定是 `/`，换成 `|` 也行
- 说法：替换路径；路径里有斜杠
- 分类：改文件内容
- 项目：Steam：替换文件路径
- 坑：要替换的内容里有 `/` 时，用 `/` 当分隔符会乱，换 `|`；正则里的 `[` `]` 要写成 `\[` `\]`

### `sed -i ...`

- 作用：直接修改原文件，不输出到屏幕
- 说法：直接改文件；就地替换；不打开文件改内容
- 分类：改文件内容
- 项目：Steam、豆瓣：改配置和脚本里的某一处

### `sed -i '30,37d'` / `r 文件` / `i 内容`

- 作用：`30,37d` 删除第 30–37 行；`行号r 文件` 在该行后面插入另一个文件的内容；`行号i 内容` 在该行前面插入一行
- 说法：删掉几行；按行号删除；插入一段；在某行前加一行
- 分类：改文件内容
- 项目：豆瓣：更新 README 时整段替换某一节

## vi

### `vi 文件`：`i`、`Esc`、`:wq`

- 作用：`i` 进入插入模式，`Esc` 回到普通模式，`:wq` 保存退出
- 说法：编辑文件；打开文件改；保存退出
- 分类：改文件内容
- 项目：全程：改 `daemon.json`、Docker 代理配置、`crontab -e`、写分析脚本
- 坑：`python:3.12-slim` 容器里没有 vi；在宿主机上改，挂载的目录容器里立刻能看到

### `:set paste`

- 作用：粘贴模式，粘贴时不自动缩进
- 说法：粘贴代码缩进乱了；粘贴模式
- 分类：改文件内容
- 项目：豆瓣：在 vi 里粘贴 Python 脚本前先开
- 坑：不开的话，粘进去的 Python 代码缩进层层叠加，直接跑不起来

### `:%d`

- 作用：删除全部行，清空文件
- 说法：清空文件；全删重写
- 分类：改文件内容
- 项目：豆瓣：整个重写 `01_decades.py` 前先清空

### `G`、`o`

- 作用：`G` 跳到最后一行；`o` 在当前行下面新开一行并进入插入模式
- 说法：跳到末尾；在最后加一行
- 分类：改文件内容
- 项目：Steam：`crontab -e` 里在最后加一条定时任务

### `/搜索`、`cw`、`r`

- 作用：`/词` 向下搜索；`cw` 改掉光标处的一个词；`r` 替换光标处的一个字符
- 说法：在文件里搜；改一个词；改一个字
- 分类：改文件内容
- 项目：练习：改 Docker 配置里的单个值

### vi：`:起,止d` / `4dd`

- 作用：删除第 起–止 行；`4dd` 从光标处删 4 行（数字放前面表示重复，`d4d` 效果一样）。多处删除时**从下往上**删，前面的行号不会变
- 说法：vi 删几行；删一段；按行号删除
- 分类：改文件内容
- 项目：Steam：03–06 改用公共模块时，`:9,34d` 删掉重复的常量、SQL 和函数

### vi：`S`

- 作用：清空当前整行并进入插入模式，保留缩进（开了 `autoindent` 时）；比 `dd` 再 `O` 少一步
- 说法：vi 重写这一行；整行替换
- 分类：改文件内容
- 项目：Steam：04 里把 `daily_ratio(load())` 那行替换成三行

### vi：`ci"`

- 作用：删掉光标所在那对引号**里面**的全部内容并进入插入模式，引号保留
- 说法：vi 改引号里的字符串；改字符串内容
- 分类：改文件内容
- 项目：Steam：06 里把 `TARGET` 从鬼武者换成影之刃零

### vi：`e` / `a` / `A`

- 作用：`e` 跳到当前单词末尾；`a` 在光标**后**插入（`i` 是前）；`A` 跳到行尾并插入
- 说法：vi 在后面插入；跳到词尾；在行尾加东西
- 分类：改文件内容
- 项目：dotfiles：`softtab` 补成 `softtabstop` 用 `e` + `a`；豆瓣：行尾加 `# git-guard: allow` 用 `A`

### vi：`x`

- 作用：删除光标处的一个字符
- 说法：vi 删一个字；删多余的字符
- 分类：改文件内容
- 项目：dotfiles：`$$HOME` 多了一个 `$`，`/\$\$` 跳过去再 `x`

### vi：`:范围s/旧/新/gc`

- 作用：替换；`%` 全文，`44,$` 第 44 行到末尾；`g` 一行多处都换，`c` 每处确认（`y` / `n`）；`/` 在模式里要写成 `\/`
- 说法：vi 批量替换；查找替换；逐个确认替换
- 分类：改文件内容
- 项目：Steam：06 列名 `"name"`→`"game"`、`"t"`→`"bj"` 共 8 处逐个确认；豆瓣：`genre`→`country`

### `~/.vimrc`

- 作用：vi 的配置文件，每次打开自动执行；里面写设置时不需要开头的冒号
- 说法：vi 默认设置；不用每次敲 set；vi 配置
- 分类：改文件内容
- 项目：dotfiles：`set autoindent expandtab tabstop=4 shiftwidth=4 softtabstop=4`；打错成 `softtab` 时打开 vi 会报 `E518 Unknown option`

### `ln -s 目标 链接名` / `unlink 链接名`

- 作用：建软链接（相当于快捷方式）；`unlink` 只删这一个链接。**删链接不删目标，写链接会写进目标**；目标被删后链接变成“断开的链接”
- 说法：软链接；快捷方式；链接配置文件；删除链接
- 分类：改文件内容
- 项目：dotfiles：`~/.vimrc` 链接到仓库里的 `vimrc`；误以为删掉了链接、`echo > ~/.vimrc` 结果覆盖了仓库文件，靠 `git checkout -- vimrc` 恢复
