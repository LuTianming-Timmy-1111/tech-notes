# 写脚本：重定向、管道、出错即停

| 写法 | 意思 |
|---|---|
| `>` | 标准输出写进文件（清空后写） |
| `>>` | 标准输出追加到文件 |
| `2>&1` | 把标准错误（2）也并进标准输出（1） |
| `\|` | 前一条的输出交给后一条当输入 |

| | `set -e` | `set -o pipefail` |
|---|---|---|
| 管什么 | 任何一条命令失败，脚本立刻停 | 管道里**任何一段**失败，整条管道算失败 |
| 不加会怎样 | 出错后继续往下跑 | 只看最后一段的结果，中间失败被掩盖 |

---

### `#!/bin/bash` + `chmod +x 脚本`

- 作用：第一行声明用 bash 运行；`chmod +x` 加执行权限，之后可以 `./脚本` 直接运行
- 说法：写个 shell 脚本；给脚本执行权限；脚本跑不起来
- 分类：写脚本
- 项目：Steam：`run_collect.sh`、`run_backup.sh`；豆瓣：`run_split.sh`、`run_all.sh`
- 坑：不加执行权限，cron 调用时报 `Permission denied`；Git 会把权限记成 `100755`，别人 clone 下来不用再 chmod

### `cd "$(dirname "$0")"`

- 作用：先进到脚本所在的目录，不管从哪里调用都能找到同目录的文件
- 说法：切到脚本所在目录；从别的目录运行找不到文件；cron 里路径不对
- 分类：写脚本
- 项目：Steam、豆瓣：所有 `run_*.sh` 的第二行
- 坑：`$0` 在脚本里是脚本路径，在交互终端里是 `bash`；把脚本内容直接粘到终端运行，结果会不一样

### `$(命令)`

- 作用：命令替换，把命令的输出当成一段文字嵌进来
- 说法：用命令的结果；把输出塞进命令里
- 分类：写脚本
- 项目：Steam：`dirname "$0"` 的结果交给 `cd`

### `>` / `>>`

- 作用：把输出写进文件；`>` 覆盖，`>>` 追加
- 说法：输出存到文件；保存结果；追加日志
- 分类：写脚本
- 项目：Steam：`venv/bin/python collect.py >> logs/collect.log 2>&1`；豆瓣：`... > schema.sql`
- 坑：日志要用 `>>`，用 `>` 每次运行都会冲掉之前的记录

### `2>&1`

- 作用：程序输出有两条通道：标准输出（1，正常结果）和标准错误（2，警告和报错）；`2>&1` 把报错也并进来
- 说法：报错也写进日志；错误输出重定向；警告没进文件
- 分类：写脚本
- 项目：Steam：cron 跑的脚本报错也要进日志；豆瓣：`docker logs 容器 2>&1 | grep` 才能搜到报错
- 坑：只写 `>` 时，mysqldump 的密码警告留在屏幕上，没进 `schema.sql`，因为警告走的是 2 号通道

### 管道 `|`

- 作用：前一条命令的输出直接交给后一条处理
- 说法：把结果交给下一个命令；串起来处理；过滤输出
- 分类：写脚本
- 项目：豆瓣：`docker exec ... mysqldump ... | sed ... > schema.sql`，导出 → 清理 → 写文件；`git log --oneline | head -15`

### `set -e`

- 作用：脚本里任何一条命令返回非 0，立刻停下，并把这个退出码带出去
- 说法：出错就停；一步失败后面不跑；脚本出错即停
- 分类：写脚本
- 项目：豆瓣：`run_all.sh` 串起 启动数据库 → 爬取 → 拆表 → 检查，任一步失败就停在那一步，看不到最后的“全部完成”

### `set -o pipefail`

- 作用：管道里任何一段失败，整条管道都算失败
- 说法：管道中间出错；管道失败也要停
- 分类：写脚本
- 项目：豆瓣：`dump_schema.sh` 里 mysqldump 接 sed，mysqldump 失败时不能让 sed 的成功掩盖过去

### `set -a; source .env; set +a`

- 作用：读入 `.env` 里的变量，`set -a` 让它们自动导出给后面启动的程序
- 说法：读环境变量文件；加载 .env；让 Python 读到密码
- 分类：写脚本
- 项目：豆瓣：`run_split.sh`、`run_check.sh` 开头；进容器跑分析脚本前也要先执行
- 坑：每次新进容器都要重新执行一遍，不然 `os.environ['MYSQL_ROOT_PASSWORD']` 报错

### `$?` / `echo $?`

- 作用：上一条命令的退出码，0 是成功，非 0 是失败
- 说法：上一条成功没有；看退出码；返回值
- 分类：写脚本
- 项目：豆瓣：`./run_all.sh; echo $?` 全部通过是 0，`check.py` 有一项不过就是 1

### `alias 名字='命令'` + `~/.bashrc`

- 作用：给长命令起个短名字；写进 `~/.bashrc` 每次登录自动生效，`source ~/.bashrc` 让它马上生效
- 说法：起别名；简化长命令；快捷命令
- 分类：写脚本
- 项目：Steam：`dev` 别名代替那条很长的 `docker run`，一敲就进开发容器
- 坑：别名里的挂载目录一开始写死成了 Steam 项目，在豆瓣目录敲 `dev` 进的还是 Steam；后来改成挂载当前目录

### 行尾 `\` 续行

- 作用：命令太长时换行接着写，`\` 后面不能有空格
- 说法：命令太长换行；多行写一条命令
- 分类：写脚本
- 项目：练习：`docker run` 一行一个参数，方便看懂
