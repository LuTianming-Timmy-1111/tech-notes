# 容器操作

| 概念 | 类比 |
|---|---|
| 镜像 | 预制菜（只读模板） |
| 容器 | 加热上桌的那一份（镜像跑起来的实例） |
| 仓库 | 超市（Docker Hub） |

`docker run` 常用参数：

| 参数 | 作用 |
|---|---|
| `-d` | 后台运行 |
| `--name 名字` | 给容器起名，之后用名字管理 |
| `-p 宿主端口:容器端口` | 端口映射 |
| `-e KEY=VAL` | 环境变量 |
| `-v 宿主路径:容器路径` | 挂载目录 / 数据卷，数据持久化 |
| `-it` | 交互终端 |
| `--rm` | 退出后自动删除容器 |
| `-w 目录` | 进容器后的工作目录 |

## 镜像和容器

### `docker pull 镜像:标签`

- 作用：从仓库下载镜像
- 说法：下载镜像；拉镜像；获取 MySQL 镜像
- 分类：容器操作
- 项目：练习：`docker pull mysql:8.0`
- 坑：国内拉镜像慢；反复 Ctrl+C 重拉更慢，已下好的层有缓存，重试会接着下

### `docker run -d --name 名字 -p ... -e ... -v ... 镜像`

- 作用：用镜像创建并启动一个容器
- 说法：启动容器；用 Docker 跑一个 MySQL；把镜像跑起来
- 分类：容器操作
- 项目：练习：跑 MySQL 容器，`-e MYSQL_ROOT_PASSWORD=...`，`-v 宿主目录:/var/lib/mysql`
- 坑：宿主机 3306 已被手装的 MySQL 占用，容器要映射到别的宿主端口；删掉容器再重建，数据还在，说明 `-v` 起作用了

### `docker run -it --rm -v 目录:/app -w /app 镜像 bash`

- 作用：起一个临时的交互容器，挂载项目目录，退出就删
- 说法：进开发容器；用新版本 Python；临时容器
- 分类：容器操作
- 项目：Steam、豆瓣：虚拟机 Python 是 3.6，用 `python:3.12-slim` 容器 + venv 开发；存成 `dev` 别名
- 坑：容器要访问外网时用 `-e HTTPS_PROXY=...` 传代理；slim 镜像里没有 vi、git

### `docker ps`

- 作用：列出正在运行的容器、端口映射、状态
- 说法：看有哪些容器在跑；容器状态；容器起来没有
- 分类：容器操作
- 项目：练习：确认 `Up` 和端口映射

### `docker images`

- 作用：列出本地镜像和大小
- 说法：看有哪些镜像；镜像多大
- 分类：容器操作
- 项目：练习：myapp 比基础镜像大 12MB，就是加进去的依赖和代码

### `docker stop 名字` / `docker rm 名字`

- 作用：停止容器 / 删除容器
- 说法：停容器；删容器；端口被旧容器占了
- 分类：容器操作
- 项目：练习：删掉 MySQL 容器再重建，验证数据卷；豆瓣：旧容器占着端口时先清掉

## 进容器、看输出

### `docker exec -it 容器 bash`

- 作用：进入正在运行的容器开一个终端
- 说法：进容器；在容器里执行命令；看容器里面
- 分类：容器操作
- 项目：练习：进 MySQL 容器看看，发现系统是 Oracle Linux，不是想象的 Debian

### `docker exec 容器 sh -c '命令'`

- 作用：在容器里执行一条命令；单引号让 `$变量` 在容器里展开
- 说法：在容器里跑一条命令；用容器里的环境变量
- 分类：容器操作
- 项目：豆瓣：`docker exec 容器 sh -c 'mysqldump -uroot -p"$MYSQL_ROOT_PASSWORD" ...'`，密码用容器自己的环境变量
- 坑：用双引号的话，`$MYSQL_ROOT_PASSWORD` 会在宿主机展开，宿主机上没有这个变量

### `docker exec -i 容器 命令 < 文件`

- 作用：把宿主机的文件喂给容器里的命令
- 说法：导入 SQL 文件；把文件传给容器里的程序
- 分类：容器操作
- 项目：豆瓣：建测试库后把 `schema.sql` 导进去，验证建表语句能用

### `docker logs 容器 2>&1 | grep 关键词`

- 作用：看容器输出的日志；`2>&1` 把报错也并进来才能 grep 到
- 说法：看容器日志；容器为什么挂了；查报错
- 分类：容器操作
- 项目：豆瓣：在容器日志里搜报错

## Docker 本身的配置

### `/etc/docker/daemon.json` 的 `registry-mirrors`

- 作用：配置镜像加速源
- 说法：拉镜像太慢；换镜像源；加速器
- 分类：容器操作
- 项目：练习：配了几个公共加速源；改完 `systemctl daemon-reload` + `systemctl restart docker`
- 坑：公共源速度看时段，慢不一定是配错了

### Docker 走代理：`docker.service.d/http-proxy.conf`

- 作用：在 systemd 配置里给 Docker 设 `HTTP_PROXY`、`HTTPS_PROXY`、`NO_PROXY`
- 说法：Docker 走代理；拉镜像走宿主机代理
- 分类：容器操作
- 项目：练习：先用 curl 测通宿主机代理，再配给 Docker
- 坑：配完用 `docker info | grep -i proxy` 确认生效

### 容器连宿主机上的服务

- 作用：容器里的 `localhost` 是容器自己；要连宿主机，用 docker0 网桥的网关地址
- 说法：容器连不上宿主机数据库；容器访问宿主机
- 分类：容器操作
- 项目：豆瓣：在开发容器里跑分析脚本，连宿主机映射出来的 MySQL；地址放在环境变量 `DB_HOST` 里，代码里给默认值
