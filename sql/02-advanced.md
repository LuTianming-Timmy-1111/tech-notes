## 子查询

### 标量子查询 / `IN` 子查询 / `EXISTS`

- 作用：标量子查询返回一个值拿来比较；`IN` 判断是否属于一列值；`EXISTS` 判断子查询有没有结果
- 说法：嵌套查询；高于平均值的；属于某个集合；存不存在
- 分类：SQL 查询
- 项目：练习：高于平均分的记录、选了某门课的学生；查“不存在”有三条路：`NOT IN`、`NOT EXISTS`、`LEFT JOIN + IS NULL`

### `FROM (子查询) t`

- 作用：把子查询的结果当成一张临时表，必须起别名
- 说法：子查询当表用；在结果上再查一次；派生表
- 分类：SQL 查询
- 项目：练习、豆瓣：先算名次再筛前 N；用 `UNION ALL` 造的假数据表

## 窗口函数

### `RANK() OVER (PARTITION BY 列 ORDER BY 列 DESC)`

- 作用：不压缩行数，给每一行算组内名次；`PARTITION BY` 分组，`ORDER BY` 定排序
- 说法：组内排名；每个类型里排第几；分组排序
- 分类：SQL 查询
- 项目：豆瓣：每个类型内按评分排名
- 坑：窗口函数不会减少行数，结果行数和原来一样

### 每组前 N

- 作用：子查询里算名次，外层 `WHERE rk <= N`
- 说法：每组前三；每个类型评分最高的几部；分组 Top N
- 分类：SQL 查询
- 项目：豆瓣：`04` 每个类型评分前 3
- 坑：不能在同一层直接写 `WHERE rk <= 3`，因为 `WHERE` 在 `SELECT` 之前执行，那时名次还没算出来

## CTE

### `WITH 名字 AS (...) SELECT ...`

- 作用：先给一段查询起名，后面像表一样用；可以连写多个，用逗号隔开
- 说法：临时结果命名；分步写查询；代替多层嵌套
- 分类：SQL 查询
- 项目：练习；豆瓣：`06` 先用 CTE 算每个类型的出现次数，再按“越少见权重越大”（IDF）给推荐加权
- 坑：CTE 只在紧跟着的那一条语句里有效

## 合并、正则、函数

### `UNION ALL`

- 作用：把几个查询结果上下拼起来；要求列数相同、类型兼容
- 说法：合并结果；上下拼接；造几行测试数据
- 分类：SQL 查询
- 项目：豆瓣：`SELECT '1994' AS year UNION ALL SELECT '19a4' UNION ALL SELECT NULL ...` 造一张假表，验证检查条件能不能抓住坏数据

### `REGEXP '^[0-9]{4}$'`

- 作用：正则匹配；`^` 开头、`$` 结尾、`[0-9]{4}` 正好 4 个数字
- 说法：正则；格式对不对；纯数字；是不是 4 位年份
- 分类：SQL 查询
- 项目：豆瓣：找出年份带后缀、多个年份导致字段错位的电影；`check.py` 年份检查
- 坑：`REGEXP '[0-9]'` 只要求“含数字”，国家名混进类型列这种问题就抓不到；要从源头按严格格式查

### 字符串函数：`CONCAT`、`SUBSTRING`、`REPLACE`、`TRIM`

- 作用：拼接、截取、替换、去首尾空白
- 说法：拼字符串；截取一段；替换文字；去空格
- 分类：SQL 查询
- 项目：练习

### `CHAR_LENGTH` vs `LENGTH`

- 作用：`CHAR_LENGTH` 数字符，`LENGTH` 数字节
- 说法：字符串长度；中文有几个字
- 分类：SQL 查询
- 项目：豆瓣：写年份检查时讲到
- 坑：MySQL 里一个汉字占 3 字节，判断中文长度要用 `CHAR_LENGTH`；另外“4 个字符”不等于“4 位数字”，`'19a4'` 长度也是 4，格式检查要用正则

### `HEX(列)`

- 作用：看字符串的十六进制编码
- 说法：看起来一样的字符；字符编码；奇怪的字符
- 分类：SQL 查询
- 项目：豆瓣：标题显示成 `——`，用 `HEX()` 确认是汉字“一”，就是电影《一一》，不是破折号

### 日期函数：`YEAR`、`DATE_ADD`、`DATEDIFF`、`DATE_FORMAT`

- 作用：取年份、加减日期、相差天数、按格式输出
- 说法：日期计算；按年份筛选；两个日期差几天
- 分类：SQL 查询
- 项目：练习
- 坑：`WHERE YEAR(日期) = 2024` 会让索引失效，改成 `日期 >= '2024-01-01' AND 日期 < '2025-01-01'`

### `CASE WHEN 条件 THEN 值 ELSE 值 END`

- 作用：按条件给出不同的值
- 说法：条件判断；分档；如果……就……
- 分类：SQL 查询
- 项目：练习

### `ROUND(值, 位数)`

- 作用：四舍五入
- 说法：保留几位小数；取整
- 分类：SQL 查询
- 项目：豆瓣：`07` 推荐分数
- 坑：排序要用原始分数，`ROUND` 只用在最后展示，先四舍五入会造成假并列；各项分数量级不同时要先缩放再加权
